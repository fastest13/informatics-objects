# Информатика: объекты и системы — тренажёр

Тренажёр по школьному учебнику информатики для 6 класса, §1–6: объекты, множества, системы. Термины и определения взяты из учебника.

Открыть: https://fastest13.github.io/informatics-objects/

## Режимы

1. **Соедини термины с определениями** — 12 случайных терминов из списка, нужно расставить определения напротив нужных понятий.
2. **Выбери определение** — термин и 5 определений: одно верное из учебника и четыре неверных. 15 случайных вопросов.
3. **Реши задачи** — 10 задач: одна расчётная с кругами Эйлера, две на логику и отношения множеств (с рисунком в разборе) и семь по разным темам информатики. В конце — одна бонусная задача с кругами Эйлера ★ (2 балла, без штрафа).

В конце — оценка, разбор ошибок и кнопка «Поделиться».

## Памятка

Страница `pamyatka.html` («Коротко о главном») — краткое содержание §1–6 с определениями, которые нужно запомнить. Её можно распечатать на A4.

## Запуск

Сборка не нужна: чистые HTML, CSS и JavaScript без библиотек. Достаточно открыть `index.html` в браузере.

Данные (термины и определения) — в `js/data.js`.
